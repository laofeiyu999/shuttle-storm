## 2. L3523 交接文：输入、蓄力、姿态／球种、后摇（本范围信息密度最高）

### 2.1 参考游戏源码事实（PB／飞羽／网球宝贝）
- **PB** [源码事实] L3523：
  - CharacterShotAnimationFinder 按未来球路、预计触点高度、前摇、可达性、场区筛选动作；跳跃和头顶突击属于情境动作，不由红档、满档或“跳杀按钮”触发。
  - 特殊动作只要求 nextShotPower > 0，普通击球没有最低蓄力档；IdealPowerZone 只是理想区间，不是出球许可。
  - 蓄力是连续归一化值，0.6 以后增速减半：约 0.18 秒到 0.6，再约 0.24 秒到满，合计约 0.42 秒。
  - 松键只保存 nextShotType／nextShotPower，在计划触球时刻后的首个 FixedUpdate 自动结算。
  - 可在空中改选球种，改选会清零力度；触球前 <0.1 秒可以取消动作；dto() 的 0.12 秒是联机力度投影。
  - 路径：PB = References/PureBadminton/，网球宝贝 = References/TennisHitBall/（L3524–3526）。
- **飞羽 curve_reimpl** [源码事实＋AI 评估] L3523：

  - 修正系数 op = ((3.92031 − 0.2h) × h + 0.0025) × v，h 按米、v 按弧度。这是采样拟合，不是官方公式。

- **飞羽实战** [AI 归纳·视频观察]：
  - 高水平回合靠提前到位、高点击球和持续的回球质量。低质量回球会形成“偏短或偏高 → 对手高点进攻 → 跨步或鱼跃 → 恢复受压”的链条。

  - HitAct 含 canStorePower、pullMoveScale、pullMinTime／pullMaxTime、canHitOverPullMaxTime；另有 MinLobHeight。普通扣杀输入 J，技能 L+J。

### 2.2 本项目输入／蓄力决定
- 不照搬 PB 的跨回合预蓄、松键保存、自动触球。理由：在缺少出界、撞网风险的项目里，这会退化成“每次都提前满蓄等待总是最优”，而用户“不希望依靠满蓄容易出界或撞网来平衡”。只吸收“姿态与球种正交、动作可先按情境启动、最终球种在临近触球时确定”。[用户决定·转述 L3523]
- **对手未出球（蓄力锁定）阶段**：可以跑，可以零蓄力挥拍、连续挥拍，但不能积攒或保存蓄力。此时长按无效，用“一次短暂震动 + 静止或锁定状态的蓄力环 + UI 动效”提示“现在无法蓄力”。[用户决定·转述 L3523]
- **对手击球后**开放本拍蓄力。长按依次进入白、黄、橙、红四档，每进入新档震动一次，共四次，只在跨档时震。击球按钮上的蓄力环与人物左侧腰线的小蓄力环同步显示档位、颜色、进度。[用户决定·转述 L3523]
- 任意档松键，就以当前蓄力开始挥拍；满蓄时系统自动执行一次松键并强制挥拍。两者都只负责启动动作，**不是自动触球、自动命中或自动选时机**，玩家可以挥空、错过球。此前讨论过的“满蓄短保持后衰减”方案不再需要。[用户决定·转述 L3523]
- 蓄力期间可以移动，但随档位渐进减速，满档减速最强，数值未定。[用户决定·转述 L3523] → **推翻 V1.4“蓄力期间不减速”**（v14 L40、L76）。

### 2.3 姿态 × 球种、三族
- 地面、空中、跨步、救球是姿态维度；杀球、劈吊、滑板吊、高远是球种维度，两者不绑死。交接文称这是“本项目已经明确”的，但原拍板点在本范围之外，需与 find_A/B 交叉核对。[用户决定·转述 L3523]
- 起跳是附加姿态。资格只看来球轨迹、头顶击球窗口、触点高度、位置、距离、剩余时间、可达性和独立起跳条件，**不看是否满蓄**；蓄力不能成为起跳门槛；空中改球种时不能把人物强制回退成地面动作。[用户决定·转述]
- 三族：
  - 杀球属于**平弧族**。
  - 下坠族：网前负责放网、搓、勾对角，网前蓄力下压可以形成拨腰线；中后场负责收吊、劈吊、滑板吊。
  - 高弧族另行组织。
  - 蓄力对三族的共同作用是逐步压平、降低出射角；高蓄力在合适的球种和触点下允许负出射角。
  - 禁止“下坠族 + 高蓄力 = 杀球”；高弧族压平后也不能无声变成另一族。[用户决定·转述]
- 同一头顶或空中前摇可以对应杀、劈吊、高远；必要时允许空中改选。但球种、路线、方向主要由临近触球的主动操作决定，不能在挥拍开始帧一次锁死，需要分段锁定。锁定帧、改选窗口、改选代价待细化；PB 的“改选清零蓄力”不能直接搬。[用户决定·转述（方向）／待定（细节）]
- 高点快速起跳点杀的因果链：对手糟糕回球 → 来球偏短、偏高或速度适宜 → 本方到位取得高触点 → 独立起跳条件成立 → 进入空中或头顶姿态 → 临近触球选择平弧族杀球。低蓄力甚至零蓄力也能形成威胁，不自动补满、不继承上一拍蓄力。[用户决定·转述]

### 2.4 质量与后摇
- 不采用网球宝贝式“非完美就普遍回出慢高球”。
- 跨步只表示没抢到最佳点，可以损失部分质量，但≠糟糕，不必然送慢高球，基础后摇很短。
- 完美 = “不附加质量后摇”，不等于零后摇。
- 糟糕的基础后摇最长；鱼跃无论蓄力与否，都有明显恢复代价。
- 蓄力后摇从零到满递增，是独立成本，与质量或动作基础后摇叠加：白档完美接近零后摇，红档完美要承担红档恢复时间。
- 跨步 + 蓄力的组合需要设上限。这一条是 AI 的数值建议，未定论。
- 上述结论的等级为 [用户决定·转述 L3523]；L3505–3511 有同样的三条体验原则。
- 质量必须真实影响回球的高度、速度、稳定性、后摇和下一拍攻守，不能只降成文字、音效或拖尾。
