# 第一公理：羽毛球手感高于一切

不管怎样，一定要设计一款符合真正羽毛球手感的羽毛球竞技游戏，而且是要做一款真正的羽毛球竞技手机游戏。这条公理大于一切。

- 核心体验：它不一定要符合物理的弹道逻辑，但打起来的手感和看起来一定要跟羽毛球很像。它不追求面面俱到的拟真，例如本作不出界，只会撞网。
- 操作与动作：它一定要是个羽毛球游戏，打起来手感优雅，玩家操作起来舒服，羽毛球专业的那些动作都在里面。

这是公理，也是真理：我一定要做一款像那么回事的、真正的羽毛球 3D 竞技手游。（依据：制作人原话，dialog L6183–L6189）

## 释义

手感优先于物理拟真。弹道可以由曲线和飞行时长驱动，规则可以简化到本作不出界、只会撞网；但球的飞行节奏、前快后慢的减速、下坠的弧线观感、击球反馈和回合节奏，必须让人觉得这是羽毛球，而不是网球、乒乓球或一颗弹性小球。

操作和动作必须真正属于羽毛球。启动、移动、跨步、引拍、挥拍、击球、收拍要自然衔接；放网、搓球、勾对角、劈吊、杀球、扑杀、高远、平高这些专业动作，在姿态、发力顺序、击球方向和实际使用场景上都要成立。

一切系统都为核心对打服务。特效不能遮住球和击球点；镜头不能妨碍判断球路；演出不能牺牲操作响应；角色成长不能变成数值压制；规则可以创新，但不能丢掉这项运动本身的特征。

任何设计只要损害了羽毛球的核心手感，不论它多华丽、多完整，都必须修改、让位或删除。本文所有章节、所有下位公理与这条公理冲突时，以这条公理为准。

## 验收

- 去掉角色、觉醒和所有华丽特效，只看步伐、挥拍和羽毛球的飞行，也能让人一眼认出这是羽毛球。
- 只保留核心对打，游戏也必须成立、耐玩，并且有真正的羽毛球手感。

## 0.1 术语

本节统一全文用词。术语中的数值以对应章节为准；标【AI初值·待调】的数值先用仿真初调，再按内测反馈调整。

### 0.1.1 时间、坐标与确定性

| 术语 | 定义 |
|---|---|
| tick | 逻辑帧。逻辑固定 60Hz，1 tick 约 16.7 ms；渲染跟随设备刷新率（60/90/120Hz），与逻辑完全解耦。所有判定只在逻辑 tick 上进行。配置表中的时间参数以毫秒填写，加载时换算为整 tick。参考：飞羽逻辑帧为 25Hz（源码事实），两者的时间窗口不可混用。 |
| 逻辑坐标 | 逻辑真值统一为 int32 厘米，渲染层再转成浮点。单打场地 5.2×13.4 m，双打场地 6.1×13.4 m，人物可移动区 9.0×16.4 m（参考：飞羽边界值（源码事实））；前发球线距网 1.9 m；网高 1.50 m（初值）。 |
| 确定性模拟 | 同一随机种子、同一输入序列，必然得到同一过程和同一落点。逻辑全程使用定点数，随机数使用 PCG32 三条独立流并显式给种子，每 60 tick 计算一次状态校验和。回放、联机、观战都建立在确定性之上。 |
| 配置外置 | 时长、系数、动作表、蓄力表、后摇表等全部放在外部配置表，动画和代码中不写死秒数。 |
| Animation Event 驱动 | 动画只负责表现。动画师交付可拉伸的蓄力循环段和出手关键帧事件；特效、音效挂在 Animation Event 上；判定时刻由逻辑 tick 决定，不由动画时间轴决定。 |
| 飞行时长 | 球从击出到落地所用的 tick 数，是本作衡量球速的唯一口径。km/h 只用于界面显示，不参与判定。 |

### 0.1.2 操作

| 术语 | 定义 |
|---|---|
| 三族三键 | 右侧按键区的三个击球键，分别对应三族弹道：切削·下坠键（下坠族）、正击·平弧键（平弧族）、挑送·高弧键（高弧族）。按钮位置在对局中固定（赛前可在键位设置里调整，见 3.1.2），按钮内的动作图标随场区、触点高度和当前档位切换；起跳不改图标。 |
| 下坠族 | 让球过网后快速下坠的一族。网前为搓球、放网、拨腰，勾对角是搓球和放网的斜线版本；中场和后场为收吊、劈吊、滑板吊。杀球不属于下坠族。 |
| 平弧族 | 弧线平、速度快的一族。包括挡网、推球、扑杀、平抽、接杀平推、软下压、硬压拦截、点杀、重杀、跳杀，以及只在前场、前中场、中场出现的反手杀球和反手起跳杀球。所有杀球都属于平弧族。 |
| 高弧族 | 把球送高送深的一族。包括挑高、推挑、高远、过渡高远、平高。 |
| 觉醒键 | 独立的通用按键，位于三个击球键上方、靠屏幕右边缘。意志满 120 时出现，按下主动开启觉醒。 |
| 操作区 | 屏幕分两个操作区：右侧按键区（三个击球键和觉醒键），左侧摇杆区。两个区域的位置、按钮大小和不透明度可在设置里分别调整（见 3.1.2）。 |
| 摇杆 | 左侧摇杆区内的虚拟摇杆，分固定位置和跟手两种模式，默认跟手【AI初值·待调】。平时负责全场移动；松键那一 tick 的 X 分量决定出球线路。 |
| 线路 | 出球的水平方向，分左、中、右三路。松键 tick 采样摇杆 X 分量（相对本方朝向），不拨或在死区内为中路；死区为 X 分量绝对值小于 0.35【AI初值·待调】。 |
| 直线与斜线 | 线路相对人物所在半区判定：拨向与人物所在半区同侧为直线，异侧为斜线。例如人物在左半区时拨左打直线搓网或放网，拨右为斜线，即勾对角。 |
| 蓄力窗口 | 允许蓄力的时段。对手击球帧那一 tick 开启，本方命中或死球时关闭；本方挥空不关闭窗口。 |
| 零蓄力挥拍 | 窗口外按下击球键，或窗口内点按即松，得到的白档挥拍。窗口外可以连续零蓄力挥拍。 |
| 蓄力锁定反馈 | 窗口外长按击球键不会积蓄，按钮圆形边缘快闪一下红光（约 0.15 s【AI初值·待调】）并短震一次，不进入蓄力。 |
| 击球键互斥 | 同一 tick 按下两个或三个击球键，本次全部无效；正在蓄力时按下另一个击球键，新按下的键无效、原蓄力继续。两种情况都弹出“不可同时多弧族击球”提示（见 3.9）。 |
| 重按规则 | 窗口开启前就已按住的键，必须松开再按下才开始蓄力。 |
| 蓄力四档 | 白（0–35 tick）、黄（36–53）、橙（54–71）、红（72 tick = 1.2 s）。到达红档的当 tick 自动松键。窗口内按下开始蓄力时长震一次，之后每进一档震动一次（白→黄、黄→橙、橙→红），共四次。 |
| 松键即挥拍 | 松开击球键立刻开始挥拍；满蓄自动松键同样立刻开始挥拍。两者都只是开始挥拍，不保证触球。 |
| 松键锁定 | 松键 tick 一次锁定族、档位、线路，以及由此确定的球种语义和动作。 |
| 命中帧 | 挥拍中球拍应与球接触的那一 tick，等于松键 tick + hitFrameOffset（地面动作 6、起跳动作 12）【AI初值·待调】。击球质量在命中帧判定。 |
| 挥拍占用 | 从松键到命中帧、再到收拍结束的整段时间。占用期间不能再次挥拍；收拍结束后可以立刻再挥，没有冷却。 |
| 蓄力减速 | 蓄力期间人物可以移动，但移速按档位逐档降低，红档最多。 |

### 0.1.3 判定与质量

| 术语 | 定义 |
|---|---|
| 场区 | 本方半场按触点到网的纵向距离分为五段，用于动作匹配和图标切换：前场 0–1.90 m（前发球线以内）、前中场 1.90–2.80 m、中场 2.80–4.20 m、中后场 4.20–5.20 m、后场 5.20 m 至底线（单打半场纵深 6.70 m）【AI初值·待调】。依据：飞羽 frontServeLine 1.9 m、frontBackLine 3.35 m（源码事实）；双打后发球线距底线 0.76 m，即距网 5.94 m。动作表分前场、中场、后场三张主表；前中场与中后场是衔接段，按第 9 章的衔接规则取用相邻主表的动作。 |
| 触点高度层 | 预测击球点所在的高度层：腿部 0.05–0.70 m、身体 0.70–1.60 m、头顶 1.60–2.55 m。逻辑身高 1.75 m，站立持拍最高触点 2.55 m【AI初值·待调】。 |
| 三圈 | 命中帧时球心与人物的水平距离分圈：完美圈 <0.60 m、跨步圈 0.60–1.20 m、糟糕圈 1.20–1.80 m，鱼跃区 1.80–2.40 m，更远够不到【AI初值·待调】。按八个 45° 扇区分别配置半径；后方三个扇区半径×0.80，且不能鱼跃。例：剩余水平距离 59 cm 为完美，60 cm 为跨步。 |
| 完美泡泡 | 也叫时机泡泡。只提示击球时机，本身没有范围，与完美判定无关。分两个阶段：阶段一（跳杀时机），来球进入本方起跳击球高度段（起跳动作的 HeightRange，约 2.55–3.20 m）且本方可以起跳的那一小段时间，泡泡快速闪紫色光（约 8 Hz【AI初值·待调】）；阶段二（击球时机引导），球下落离开起跳段后，变成浅蓝色光边缘的慢闪泡泡（约 2 Hz【AI初值·待调】），一直闪到球落地，提示越早、越高击球越好，必须快点走到落点附近。球被击中或落地后泡泡消失。泡泡只显示给击球方本人（双打时队友的泡泡也不显示给我），观战视角显示场上所有人的泡泡。 |
| 落点标记 | 来球落点处的标记，以落点为中心向外画三圈，代表完美、跨步、糟糕的击球范围（基准半径 0.60 / 1.20 / 1.80 m）。地面投影只作提示，实际判定按命中帧球心与人物的距离。与泡泡无关。落点提示 LandingMarker 分三档（关闭、简洁、完整）。满蓄跳杀标记见 3.7.5。 |
| 击球质量 | 完美、跨步、糟糕三档，另有挥空（whiff）。质量只由命中帧时球心与人物的水平距离（三圈）决定，不看泡泡；起跳击球触发即记完美（起跳击球是最高击球点）。质量真实影响回球弹道和本方后摇。判出完美或糟糕时在击球点旁弹出质量签（弹字）：笔刷底加白字，完美为红色（#FF2020），糟糕为灰色（#9A9A9A）【AI初值·待调】，显示约 36 tick（0.6 s）【AI初值·待调】，结尾从左往右抹掉；普通（跨步）击球不弹字。造型参考飞羽青春。 |
| 挥空 | 命中帧时球不在三圈之内，或不在所选动作的 HeightRange 之内。一次来球可以多次挥拍；只有球落地且这一来球零命中时，才结算为挥空。 |
| 糟糕救球 | 被动够球的糟糕回球统称，只有两种动作：大跨步糟糕救球、鱼跃救球。糟糕圈内的回球一律是大跨步糟糕救球，与人物是否在移动无关：头顶层或身体层来球在糟糕圈时，用原击球动作加大跨步步法变体 VA02；对方杀球落入糟糕圈同样是大跨步糟糕救球，不单列接杀类别。鱼跃区的回球是鱼跃救球。 |
| 网前被动回球 | 网前低位来球时糟糕回球的方向分支，没有任何豁免或特权。 |
| 鱼跃 | 来球在鱼跃区、且在正前或侧前三个扇区时自动触发的救球动作（鱼跃救球），没有按键。体力低于 25% 时禁用。 |
| 起跳 | 附加状态，与蓄力无关。头顶来球的预测触点高度落入某个起跳动作的 HeightRange（一般 2.55–3.20 m，由动作表配置）【AI初值·待调】、且人物到位时间足够时自动起跳，否则播放地面动作。零蓄力也可以起跳点杀。起跳击球触发即记完美；初版不另计落地后摇，后续按测试反馈调整。 |
| 后摇 | 击球后人物不能自由移动和再次挥拍的恢复时间，等于质量后摇加蓄力后摇。对抗的核心之一是抓对方后摇的时间差。 |
| 球种语义 | 松键时锁定的球种标签，例如杀球、扑杀、平抽、推球、吊球、网前、高远、挑高、发球、救球。规则只读标签，禁止按动画编号判断。 |
| 质量拖尾 | 球路特效只由击球质量决定：完美为红色拖尾（#FF2020），跨步为黄色拖尾（#FFC800）；糟糕为短灰白阴影拖尾（长度约 0.08–0.12 s 飞行距离，α 约 0.4），触球瞬间球体闪白 0.08–0.12 s，整段飞行球体轻度自发光，人物身上只有一小团浅色碎光，并伴随现实羽毛球那种清脆的救球声，提示对方可以进攻【AI初值·待调】。拖尾色相是质量标签的纯函数，不受角色、皮肤和觉醒覆盖；杀类拖尾在色相不变的前提下加宽加亮（第 10 章）。 |
| 抵消 | 防守方蓄力对糟糕回球的修正。R = 防守相对蓄力 × K（0.6）×（1 − 进攻蓄力% × Km（0.25））。只修正糟糕回球的顶点、时长和收中，不改质量标签。 |

### 0.1.4 规则与资源

| 术语 | 定义 |
|---|---|
| 撞网 | 本作唯一的失误判负形态。黄档及以上的下坠族、平弧族球，按几何判定，在网平面处球心高度 ≤1.50 m 即撞网，击球方失分。白档弹道生成时保证过网；高弧族永不撞网；发球不参与撞网判定；没有触网变轨。 |
| 本作不出界 | 左右边线和底线一律不出界，落点钳制在本场边界之内。 |
| 体力 | 满值 100。每次击球按档位消耗，杀球消耗更多。体力为 0 时移速降为 0.80 倍；低于 25% 时禁用鱼跃。 |
| 意志 | 满值 120。完美、跨步、完美接杀、得分获得意志，糟糕类不获得。完美接杀与完美不叠加（只得完美接杀一项），杀球直接得分与得分不叠加（只得杀球直接得分一项）。意志满时出现觉醒键。 |
| 觉醒 | 短时移速增益：持续 8 s，移速 +10%。不影响蓄力、挥拍、判定、体力、意志和球速。表现为加速白线、下肢模糊拖影、按钮金色呼吸光晕和音效（第 10 章），开启 4 s 后可以提前取消。 |
| 均衡模式 | 开房选项。开启后无视双方转职属性与等级，比赛只用 7 分制。 |
| 回放 | 由随机种子加双方输入序列确定性重建的比赛录像，不录视频，不录逐帧坐标。 |
| InputFrame | 每 tick 上行的输入帧，2 字节：移动方向 5 bit（32 向）、是否移动 1 bit、四个按键的按住状态 4 bit（下坠、平弧、高弧、觉醒）、预留 6 bit。按下沿和松开沿由服务端差分得到。 |

## 0.2 竞品对比

本作以《飞羽青春》的快节奏对打为玩法基座，在其上叠加四档蓄力，并用撞网取代界外判罚。飞羽一列来自对第三方源码的阅读转述（源码事实），PB 一列来自公开视频与玩法观察；两列都只作研究，不构成本作需求。

### 0.2.1 对比表

| 维度 | 飞羽青春 | Pure Badminton（PB） | 本作 |
|---|---|---|---|

# 第 1 章 设计公理

本章是第一公理之下的八条下位公理。下位公理之间冲突时按编号先后裁决；任何一条与第一公理冲突时，以第一公理为准。

## 1.1 公理一：三族三键，操作极简

右侧按键区只有三个击球键和一个觉醒键，左侧摇杆区只有一个摇杆。三个击球键对应下坠、平弧、高弧三族弹道，共同覆盖对方全场；摇杆负责全场移动，出球只分左、中、右三路。

对局中按钮位置永远固定（赛前可在键位设置里调整位置、大小和不透明度），变化的只是按钮里的动作图标。玩家不需要记忆组合键，就能从图标上看出当前这一拍能打出什么动作。

具体动作由系统按场区、触点高度、是否满足起跳条件和蓄力档位自动匹配，玩家只做三件事：选族、选线路、决定蓄多久。

## 1.2 公理二：对手击球后才能蓄力

蓄力窗口只在对手击球帧之后开启。窗口外仍可以零蓄力挥拍，而且可以连续挥；长按不会积蓄，并通过按钮边缘快闪红光和短震告诉玩家现在不能蓄力。

松键即挥拍，蓄满自动松键，出手时机完全交给玩家。没有提前蓄满后保存的做法，也没有自动触球；时机不对就会挥空或错过球。

## 1.3 公理三：蓄力压低压平落深，不改族

蓄力让三族弹道一起变得更低、更平、更快、落点更深，高档时出射角可以为负。蓄力不会把一族球变成另一族：下坠族蓄满仍是吊球或拨腰，不会变成杀球；高弧族压平后是平高或推挑，仍属高弧族。

蓄力的收益和风险同时存在。黄档及以上的下坠族、平弧族球可能撞网；高档蓄力带来更大的移动减速和更长的蓄力后摇；对手看到的来球更快，可蓄时长更短。

## 1.4 公理四：质量由位置与时机决定

击球质量只由命中帧时球与人物的空间关系决定：完美圈为完美，跨步圈为跨步，糟糕圈和鱼跃区为糟糕，够不到为挥空；起跳击球触发即记完美。完美泡泡只提示时机，不参与判定。

质量必须真实影响这一拍和下一拍。完美没有质量后摇，回球最稳；跨步略慢、收敛略差，但不抬高、不送杀；糟糕回球更高、更慢、更靠中，给对方制造进攻机会，同时本方后摇最长。

## 1.5 公理五：质量差异不靠额外人物动作

完美击球不增加任何额外的人物动作，也不附加质量后摇。质量差异通过球路拖尾、质量签、击球音效、镜头微震和意志获取来表达。

球路特效只表达击球质量，拖尾色相是质量标签的纯函数。角色、皮肤、觉醒和杀球特效都不能覆盖它。表现优先级为：球体可读性 ＞ 击球质量提示 ＞ 对手动作预警 ＞ 觉醒状态 ＞ 角色装饰。

## 1.6 公理六：觉醒只加速，不新增动作

觉醒只把移速提高 10%，持续 8 s。它不缩短蓄力，不改变蓄力窗口、挥拍占用、判定半径、体力、意志和球速，也不解锁任何专属动作。

觉醒不新增动作资产，只改变材质、特效（加速白线、下肢模糊拖影、金色呼吸光晕）、音效和后处理。转职路线、五项基础属性和转职后的觉醒爆发技属于后期版本，当前只预留接口（见 2.5.2），届时也必须遵守第一公理。

## 1.7 公理七：曲线驱动，本作不出界，只会撞网

弹道由飞行时长和六个曲线参数驱动，借用飞羽前快后慢、末段下坠的剖面形状，不做重力积分和空气动力学模拟。同一输入在任何设备上得到同一条曲线。

落点始终钳制在本场边界之内，本作不出界。撞网是唯一的失误判负形态：白档保证过网，高弧族永不撞网，黄档及以上的下坠族和平弧族按网平面几何判定撞网。

## 1.8 公理八：确定性与解耦

逻辑固定 60Hz，与渲染完全解耦；所有判定只在逻辑 tick 上进行，所有设备使用同一规则，不按设备留容差。

逻辑坐标为 int32 厘米，运算使用定点数；随机数使用 PCG32 三条独立流并显式给种子；每 60 tick 计算一次状态校验和。所有时长和系数配置外置；动画、特效和音效只做表现，由 Animation Event 驱动，不参与判定。回放、联机和观战都由这一条保证一致。

# 第 3 章 操作映射

## 3.1 输入布局

### 3.1.1 按键与族

屏幕分两个操作区：左侧摇杆区放虚拟摇杆，右侧按键区放三个击球键和一个觉醒键。三个击球键在对局中位置固定，任何时候都不移动、不合并、不隐藏。

| 按键 | 族 | 回合中的典型动作 | 发球 |
|---|---|---|---|
| 切削·下坠键 | 下坠族 | 搓球、放网（斜线版即勾对角）、拨腰、收吊、劈吊、滑板吊 | 发小球 |
| 正击·平弧键 | 平弧族 | 挡网、推球、扑杀、平抽、接杀平推、软下压、硬压拦截、点杀、重杀、跳杀；前场到中场的反手杀球、反手起跳杀球 | 发平快球 |
| 挑送·高弧键 | 高弧族 | 挑高、推挑、高远、过渡高远、平高 | 发高远球 |
| 觉醒键 | 无 | 意志满 120 时出现，按下开启觉醒 | 不参与 |

各场区、各档位下每个键对应的具体动作，见第 9 章动作表。觉醒键位于三个击球键上方、靠屏幕右边缘。

### 3.1.2 操作区与键位设置

- 右侧按键区：三个击球键和觉醒键。
- 左侧摇杆区：摇杆有两种模式。固定位置模式下，摇杆底盘固定在设定位置；跟手模式下，玩家在摇杆区内任意点触，摇杆底盘立即出现在触点并开始滑动走位。默认跟手【AI初值·待调】。
- 键位设置：在设置里可分别调整两个区域的位置、按钮大小和不透明度，参考全明星街球派对的键位设置（分区拖拽、大小滑条、不透明度滑条、恢复默认）。这就是键位的可调范围。对局中不可调整。

## 3.2 摇杆三路

### 3.2.1 移动

摇杆负责全场移动，方向量化为 32 向。基础移速前进和左右 3.80 m/s、后退 3.10 m/s，按椭圆合成，没有加速度（每 tick 6.33 / 5.17 cm）。参考：飞羽移速（源码事实）。

最终移速 = 基础移速 × 体力乘数 × 蓄力减速乘数 × 觉醒乘数。体力乘数在体力大于 0 时为 1.00、等于 0 时为 0.80；蓄力减速乘数见 3.4；觉醒乘数为 1.10。

### 3.2.2 线路

线路在松键那一 tick 采样摇杆 X 分量，按本方朝向换算为左、中、右三路。不拨或在死区内为中路，死区为 X 分量绝对值小于 0.35【AI初值·待调】。摇杆的 Y 分量不参与线路选择。

线路拨向与人物所在半区同侧为直线，异侧为斜线。网前的勾对角（搓球和放网的斜线版本）、中场和后场的斜线吊和斜线杀都由此产生。例如人物在左半区网前，摇杆拨左打直线搓网或放网，拨右才是勾对角。动作图标里没有单独的勾对角，只显示搓球或放网。

蓄力期间推着摇杆移动，不会影响线路，直到松键那一 tick 才读取。

## 3.3 蓄力窗口

### 3.3.1 开启与关闭

蓄力窗口在对手击球帧那一 tick 开启，在本方命中或死球时关闭。本方挥空不关闭窗口，只要球还没落地，就可以再次蓄力挥拍。

### 3.3.2 窗口外

- 窗口外按下击球键，立即以白档零蓄力挥拍；收拍后可以马上再挥，因此可以连续零蓄力挥拍。
- 窗口外长按击球键不积蓄，按钮圆形边缘快闪一下红光并短震一次，告诉玩家现在不能蓄力。
- 窗口开启前就按住的键，窗口开启后不会自动开始蓄力，必须松开再按下。

### 3.3.3 可蓄时长

玩家可蓄的时长取决于来球的飞行时长。估算方式：可蓄量 ≈（来球飞行时长 − 约 0.25 s 反应时间）÷ 1.2 s【AI初值·待调】。对手打出的球越快，本方能蓄到的档位越低，这就是高档蓄力压迫对手的方式。

## 3.4 四档蓄力

### 3.4.1 档位表

| 档位 | 蓄力区间 | 颜色 | 时长乘数 durationMul | 收敛 Gather | 顶点乘数 apexMul | 移速乘数 chargeMoveMul | 蓄力后摇 |
|---|---|---|---|---|---|---|---|
| 白 | 0–35 tick | #FFFFFF | 1.00 | 0 | 1.00 | 0.95 | +0 tick |
| 黄 | 36–53 tick | #FFD23F | 0.88 | 50 | 0.92 | 0.90 | +3 tick |
| 橙 | 54–71 tick | #FF8A1F | 0.80 | 80 | 0.84 | 0.85 | +6 tick |
| 红 | 72 tick（1.2 s） | #FF2E2E | 0.74 | 100 | 0.76 | 0.80 | +9 tick |

蓄力区间以外的各列均为【AI初值·待调】。durationMul 越小球越快，配置时不能做反；Gather 为 0–100 的整数。

### 3.4.2 档位规则

- 蓄力按整 tick 计算，档位由按下沿到松键 tick 之间、处于窗口内的 tick 数决定。
- 到达红档的当 tick 自动松键，立即开始挥拍。蓄满不能保持，也不会衰减后等待。
- 蓄力期间可以移动，移速按当前档位的 chargeMoveMul 降低，从白档的轻微减速起步，红档最多。
- 蓄力让三族弹道一起压低、压平、落深，高档出射角可以为负；蓄力不改变族。
- 觉醒不乘算蓄力：觉醒期间蓄力速度、档位区间、窗口规则都不变。

## 3.5 松键、命中与锁定

### 3.5.1 松键即挥拍

松开击球键立即开始挥拍；蓄满自动松键同样立即开始挥拍。两者都只是开始挥拍，不保证触球。时机过早或过晚，就会挥空或错过球。

### 3.5.2 一次锁定

松键 tick 一次锁定以下内容，挥拍过程中不再改变：族、档位、线路、球种语义、具体动作（地面或起跳、正手或反手、动作编号）、命中帧。

动作由系统按场区、触点高度层、起跳条件和档位自动匹配，玩家不单独选择。

当前版本采用一次锁定（方案 A）。如果内测反馈线路不够灵活，改为方案 B：族和档位仍在松键 tick 锁定，线路推迟到命中帧前再读取【待定：以内测结论为准】。

### 3.5.3 命中帧判定

命中帧 = 松键 tick + hitFrameOffset，地面动作为 6，起跳动作为 12【AI初值·待调】。按键决定蓄力，命中帧决定判定，两者之间只差 hitFrameOffset。

命中帧时，球必须位于三圈之一，并且位于所选动作的 HeightRange 之内，否则挥空。质量只看三圈（见 0.1.3）：命中帧剩余水平距离小于 0.60 m 即为完美，起跳击球触发即记完美。完美泡泡只提示时机，不参与判定。

### 3.5.4 起跳与鱼跃不需要按键

- 起跳：头顶来球的预测触点高度落入某个起跳动作的 HeightRange、且人物到位时间足够时，松键后自动播放起跳动作；否则播放地面动作。起跳与蓄力档位无关，零蓄力也可以起跳点杀。起跳击球触发即记完美。初版不另计落地后摇，后续按测试反馈调整。
- 鱼跃：来球在鱼跃区、且在正前或侧前三个扇区时自动触发鱼跃救球。体力低于 25% 时禁用。

### 3.5.5 挥空与无来球挥拍

一次来球可以多次挥拍，挥空不关闭蓄力窗口。只有球落地、且这一来球没有任何一次命中时，才结算为挥空。没有来球时的空挥只播放动作，不记挥空。

## 3.6 后摇与挥拍占用

### 3.6.1 后摇构成

总后摇 = 质量后摇 + 蓄力后摇。后摇期间人物不能自由移动，也不能再次挥拍。

| 击球质量 | 质量后摇 | 说明 |
|---|---|---|
| 完美 | 0 tick | 只有 4 tick 动画融合，不限制操作 |
| 跨步 | 12 tick | 与蓄力后摇相加后，总后摇上限 20 tick |
| 大跨步糟糕救球 | 36 tick | 糟糕圈内的回球一律按此结算，含对方杀球落入糟糕圈 |
| 鱼跃救球 | 55 tick | 鱼跃区回球，含倒地和起身 |

以上数值均为【AI初值·待调】。蓄力后摇按 3.4.1 的档位表叠加。糟糕救球只有大跨步糟糕救球和鱼跃救球两种，糟糕圈内不再细分其他糟糕类别。起跳初版不另计落地后摇。

### 3.6.2 设计意图

完美没有质量后摇，但仍要承担蓄力后摇：白档完美几乎可以立刻回位，红档完美要付出红档的恢复时间。

跨步的后摇不明显，跨步加蓄力也不能长到影响手感，所以设总后摇上限。

糟糕救球的后摇最长，鱼跃救球又长于大跨步糟糕救球。后场红档跳杀被对手挡到网前时，进攻方会因后摇来不及上网，这是玩家自己的战术选择。对抗的核心之一，是抓住对方后摇的时间差。

### 3.6.3 挥拍占用

挥拍占用从松键开始，经过命中帧，到收拍结束为止。占用期间按击球键无效；收拍结束后可以立刻再挥，没有冷却。

挥拍核心段锁定移动；蓄力期间上半身播放蓄力姿势，下半身继续步法，两层分别驱动。正手和反手的架拍、引拍、蓄力姿势不同，反手单独制作动画资产。

## 3.7 界面反馈

### 3.7.1 击球键蓄力环

- 常态：三个击球键为半透明浅灰色，不透明度 35%【AI初值·待调】（玩家可在键位设置里调整，见 3.1.2）。
- 点按：同色系深浅变化，按下加深，松开恢复；按钮不放大，也不从中心向外填充。
- 窗口开启：按钮外缘出现 2 px 细白环【AI初值·待调】。
- 按住蓄力：只在按钮圆形边缘显示当前档位颜色的光效，带加速感的微脉冲，脉冲频率随档位升高而加快：白 2 Hz、黄 3 Hz、橙 4 Hz、红 6 Hz【AI初值·待调】。
- 进入新档：边缘亮一下，0.1 s【AI初值·待调】。
- 松键：边缘光在 0.12 s 内收回并闪白【AI初值·待调】。
- 窗口外长按：按钮圆形边缘快闪一下红光，约 0.15 s【AI初值·待调】，同时短震一次，不进入蓄力。
- 觉醒期间：金色 #FFC83D 呼吸光晕保留，叠在边缘光外侧，频率 1.2Hz【AI初值·待调】。
- 以上按钮光效可在“操作设置”里开关。

### 3.7.2 腰侧蓄力小环

人物左侧腰线处有一个世界空间的蓄力小环，与按钮蓄力环同步显示档位和进度，只对本人显示。

- 位置：环心离地 1.0 m，在躯干左侧 0.45 m；世界半径 0.20 m，环宽 0.045 m；1080p 下屏幕直径不小于 48 px【AI初值·待调】。
- 窗口开启时显示 35% 不透明度的底环；蓄力时只在环边显示当前档位颜色的光，并从 12 点方向顺时针推进表示进度，不做中心填充；松键后 0.15 s 淡出【AI初值·待调】。

### 3.7.3 动作图标切换

每个击球键内的图标 = f（场区，触点高度层，当前档位）。系统根据来球预测实时刷新图标；按住蓄力时，图标随档位升级实时切换。例如前场的切削·下坠键，白档显示搓球，黄档显示放网，橙档和红档显示拨腰；后场的切削·下坠键，白档显示收吊，黄档和橙档显示劈吊，红档显示滑板吊。前中场、中后场按第 9 章的衔接规则取前场、中场或后场的图标。

- 起跳不做图标变体：满足起跳条件时，松键后自动播放起跳版动作，图标仍显示地面版球种。
- 勾对角不单独出图标：线路拨向斜线时，图标仍显示搓球或放网。
- 不做不可用原因提示。
- 图标切换的防抖和显示样式设置等细节【待定】。

### 3.7.4 对手信息

对手的击球键、蓄力环、发球条和体力条都不显示。本方能观察到的唯一信号，是对手手腕和球拍上的聚气特效（淡白色线条向手腕和拍面汇聚，档位越高线条越多，橙红档线尾带档位色），以及对手的架拍动作。观察聚气特效持续的时长和密度，就能判断来球的档次。

### 3.7.5 时机泡泡、落点标记与满蓄跳杀标记

- 时机泡泡：分两阶段，阶段一紫色快闪（约 8 Hz【AI初值·待调】）提示跳杀时机，阶段二浅蓝色光边缘慢闪（约 2 Hz【AI初值·待调】）引导尽早、尽高击球，一直闪到球落地；球被击中或落地后消失。泡泡只提示时机，与完美判定无关。泡泡只显示给击球方本人（双打时队友的泡泡也不显示给我），观战视角显示场上所有人的泡泡。定义见 0.1.3。
- 落点标记：以来球落点为中心向外画三圈，代表完美、跨步、糟糕的击球范围（基准半径 0.60 / 1.20 / 1.80 m），只作提示，判定以命中帧球心与人物的距离为准。LandingMarker 分关闭、简洁、完整三档。
- 满蓄跳杀标记：系统动态计算本方从当前位置、按当前移速赶到起跳击球点后，剩余可蓄 tick 是否 ≥ 66（约 92%，最低也接近满蓄）【AI初值·待调】；满足时落点标记切换为醒目的特殊标记，含义是“赶紧移动到这里，可以满蓄力双脚起跳扣杀”。形状不用星形，也不参考飞羽星标扣球；建议为红橙双层脉冲环加四道向中心收拢的光箭，再加中心短促光柱，出现时一次放大弹出 0.15 s【AI初值·待调】。标记出现期间，平弧键边缘同步亮红橙色光（与蓄力档位光叠加，标记消失即熄灭），提示“用平弧键蓄满起跳扣杀”。只对接球方本人显示（双打队友不显示），观战视角全部显示。

## 3.8 震动

- 窗口内按下开始蓄力（进入白档）时长震一次；之后每进一档震动一次（白→黄、黄→橙、橙→红），共四次。红档那一次与自动松键同时发生。
- 窗口外长按击球键，短震一次，同时按钮边缘快闪红光，提示当前不能蓄力。
- 按钮光效和震动可在“操作设置”里分别开关。
- 各次震动的时长和强度在配置表中填写【待定】。

## 3.9 按键组合规则

- 同一 tick 内的输入按固定顺序处理：觉醒 → 松开 → 按下。
- 觉醒键与击球键互不影响：蓄力中按觉醒键，蓄力继续；觉醒开启不打断挥拍。
- 挥拍占用期间，任何击球键按下都无效。
- 击球键互斥：同一 tick 按下两个或三个击球键，本次全部无效，按键区上方弹出小图标提示“不可同时多弧族击球”约 0.8 s【AI初值·待调】，玩家需要重新点按或长按。
- 正在蓄力时按下另一个击球键：新按下的键无效，原蓄力继续，弹出同一提示。手指从原键滑出到另一个键上，仍算原键。
- 窗口开启前已按住的键必须松开重按，才开始蓄力。
- 得分后的复位、转场、暂停期间，按键无效。
- 触摸事件按系统触摸时间戳归入对应 tick；客户端合并后上行，服务端和录像只认合并后的结果。

## 3.10 发球操作

发球前，发球方和接发方都可以在各自的对角发球半场区域内自由移动；发球击出后，视角从发球机位平滑过渡到战斗主视角，过渡 15 tick（0.25 s）【AI初值·待调】，过渡曲线只由 tick 推导；参考飞羽青春约 7–8 帧（30 fps）的过渡。

发球时三个键分别对应三种发球：切削·下坠键发小球，挑送·高弧键发高远球，正击·平弧键发平快球。正反手按真实规则选取，线路同样分左、中、右。

按住发球键时显示发球条，满条 50 tick，满条自动发出，发球强度系数 0.70。发球时限 10 s，超时失分。

发球是特殊环节：发球蓄力只改变弹道和球速，不扣体力；发球不参与撞网判定，发球弹道保证过网；发球弹道使用单独的发球曲线表，与实战弹道逻辑分开。

## 3.11 输入帧

每 tick 上行一个 InputFrame，共 2 字节：移动方向 5 bit（32 向）、是否移动 1 bit、四个按键的按住状态 4 bit（下坠、平弧、高弧、觉醒）、预留 6 bit。

按下沿和松开沿由服务端根据相邻帧差分得到；线路取松键 tick 的摇杆 X 分量（相对本方朝向）。每包冗余携带前 2 帧输入。蓄力值不上行，由服务端按窗口开启 tick、按下沿 tick 和松键 tick 重算。双打在同一 tick 合包下发，按“定时不等待”处理。

# 第 4 章 核心玩法循环

## 4.1 一拍的循环

每一拍都按同一顺序推进：

- 对手击球：本方蓄力窗口开启；屏幕显示来球落点标记和时机泡泡，本方观察对手的聚气特效和架拍动作。
- 判断与移动：用摇杆移动到合适位置，按钮图标随场区和触点高度刷新。
- 蓄力：按住所选族的击球键蓄力，档位越高，移动越慢；四次震动和按钮边缘光、腰侧小环提示当前档位。
- 出手：松键或蓄满自动松键，锁定族、档位、线路和动作，开始挥拍。
- 命中：命中帧按三圈判定完美、跨步、糟糕或挥空；球按族、档位、质量和线路生成弹道，球路拖尾和质量签显示质量。
- 恢复：本方进入后摇，然后回位；对方蓄力窗口开启，进入下一拍。

## 4.2 攻守博弈

### 4.2.1 蓄力与时间

高档蓄力让回球更快、更平、更深，压缩对手可蓄的时长，逼对手只能低档回球甚至糟糕救球。代价是蓄力时移动变慢、后摇变长，黄档以上的下坠族和平弧族球还可能撞网。

因此每一拍都存在两种选择：快压，不给对手蓄力的时间；或者打高打深，为自己争取回位时间。

### 4.2.2 质量与机会

完美回球最稳，并且没有质量后摇；跨步略慢、收敛略差，但不送机会；糟糕回球更高、更慢、更靠中，并以短灰白拖尾、闪白、球体轻度自发光和清脆的救球声提示对方，这就是对方的机会球。

防守方可以用蓄力抵消部分糟糕回球的劣势，进攻方的高档蓄力又会压制这种抵消。抵消只修正弹道，不改质量标签。

### 4.2.3 后摇时间差

后摇是攻守转换的关键。对方完美低档回球后几乎立刻回位；对方高档进攻或糟糕救球后，会有一段明显的后摇。抓住这段时间差打对方的空当，是得分的主要方式之一。

后场红档跳杀如果没有打死，被对手挡到网前，进攻方会因后摇来不及上网，下一拍很可能变成糟糕救球。

### 4.2.4 起跳与终结

机会球到来时，球的高度落入起跳范围、人物又能及时到位，就会自动起跳，起跳击球触发即记完美。起跳与蓄力无关：零蓄力也能起跳点杀，红档可以双脚满蓄杀；时机泡泡的紫色快闪段提示跳杀时机，满蓄跳杀标记提示“赶到这里可以满蓄双脚起跳扣杀”。终结动作的选择仍然只靠族、档位和线路。

扑杀要求平弧键蓄到橙档及以上，并且人物必须在移动中：松键前 6 tick 内位移累计 ≥ 15 cm 且摇杆输入非零【AI初值·待调】。站着不动，即使来球很高也打不出扑杀，按推球出手，图标显示推球。扑杀可以在前场和前中场打出，满足起跳条件时为起跳扑杀。前场、前中场和中场还可以打出反手杀球和反手起跳杀球；中后场和后场的反手位来球，仍播正手（绕头）杀球和正手跳杀。

### 4.2.5 网前斗网节奏

- 网前双方都想先拿高击球点。网前不能长蓄力，黄档以上的下坠族和平弧族在低点出手容易撞网，一般白档搓网或勾对角，或者黄档浅放网。
- 谁先回出低质量、高弧度的球，对手就可能用平弧族把球推到后场，或者在移动中扑杀。低质量回球留给扑杀方的蓄力和走位时间要刚好够到橙档，这个时间差是网前博弈的设计重点【AI初值·待调，在弹道仿真中初调】。
- 参考飞羽：网前一直拿高点打近球，球快速下坠，对手很难打出完美；对方若在低点还打近球，球会飞高，被远球直接推到后场。

## 4.3 资源循环

| 资源 | 获取 | 消耗与影响 |
|---|---|---|
| 体力（满 100） | 【待定：恢复规则】 | 每次击球按档位消耗：白 −1、黄 −2、橙 −3、红 −4，杀球 ×1.5；起跳额外 −1；大跨步糟糕救球额外 −3、鱼跃救球额外 −6【AI初值·待调】，两者分开扣、不叠加，在救球动作出现的那一 tick 判定扣除（松键锁定为救球动作的 tick，或鱼跃自动触发的 tick）；发球蓄力不扣体力；体力为 0 时移速 ×0.80；低于 25% 时禁用鱼跃 |
| 意志（满 120） | 完美 +4、跨步 +1、完美接杀 +20、杀球直接得分 +12、得分 +6；糟糕类不获得。完美接杀与完美不叠加，杀球直接得分与得分不叠加 | 满 120 时出现觉醒键 |
| 觉醒（8 s） | 意志满后主动开启 | 移速 +10%；开启 4 s 后可提前取消 |

体力约束高档蓄力和杀球的频率：一直红档重杀，后段会失去鱼跃，最终连移速都会下降。例：白档鱼跃救球 = 1 + 6 = 7%，红档跳杀 = 4×1.5 + 1 = 7%。意志例：完美接杀后对方没接到 = 完美接杀 +20 + 得分 +6 = +26。意志奖励完美和完美接杀，觉醒再把这份优势转化为更快的步伐，帮助玩家抓住更多后摇时间差。

## 4.4 一局与一场

一局从发球开始：发球前双方可在各自的对角发球半场内自由移动，发球方选择小球、平快球或高远球和线路，发球击出后视角平滑过渡到战斗主视角，进入回合；回合在球落地、撞网或发球超时时结束，得分后播放慢放或精彩球回放，再经涂鸦转场复位，进入下一次发球。

每局 7 分，6:6 后须领先 2 分，10 分封顶；三局两胜。比赛开场展示双方人物和属性（不可跳过），赛后是获胜者庆祝和结算。双打对局时长【待定】。

## 4.5 新手体验

本作没有新手教学，入门体验靠规则本身保证：

- 白档弹道生成时保证过网，高弧族永不撞网，新手先用低档和高弧族就不会白白丢分。
- 本作不出界，任何线路都落在场内。
- 糟糕回球只送对方机会，不直接送分；新手可以在被动中靠大跨步糟糕救球、鱼跃救球和高弧过渡把回合打下去。
- 按钮图标直接显示当前能打出的动作，不需要记忆组合。

高手的上限来自蓄力档位的取舍、抢高点击球的时机（时机泡泡只作提示）、线路的直斜变化，以及对对方后摇时间差的把握。
