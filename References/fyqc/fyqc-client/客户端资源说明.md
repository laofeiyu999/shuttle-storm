## 二、视频专项说明（video_real）

- 之前 `video/` 目录的 269 字节 .mp4 均为 **VideoClip 元数据存根**（内含 Jenkins 构建路径与 `archive:/CAB-xxx` 资源引用），非视频本体
- 真实视频字节存储在 bundle 内 `.resource` 资源流段
- 导出方法：在 1658 个 bundle 中全量扫描 `ftyp` 签名 → 按 MP4 box 走法（ftyp/uuid/free/mdat/moov）精确定界 → 校验含 moov+mdat → 按 `m_OriginalPath` 尾段（如 `2300005.m4v`）重命名
- 验证结果：抽样 3 个均含 `avc1`（H.264）编码标记，moov/mdat box 完整，可直接用播放器打开
- 编号规律：21xxxxx（新手教学，43 个）/ 22xxxxx（角色/剧情）/ 23xxxxx（活动/其他）
- 映射表：`video_real\_mapping.txt`（bundle→编号→帧率→原路径）

## 四、注意事项

1. **用途边界**：本目录资源仅用于原版客户端
2. `.animclip.bin` 为 Unity 原始动画数据；如需 .fbx 需 Unity/Blender 批量转换
3. `.wem` 音频为 Wwise 格式，需 ww2ogg/foobar2000 插件转换后播放
4. `.obj` 网格不含蒙皮权重（蒙皮在 SkinnedMeshRenderer 组件数据中），如需完整角色绑定可按需补导
5. TextAsset 全部 346 个导出成功（首次 318 失败已用 m_Script/script 属性修复）
6. 视频 .m4v 与音频 .wem 均为游戏原始编码；本地运行客户端时无需转换
